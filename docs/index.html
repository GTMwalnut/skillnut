How it works

Install the plugin in Claude Code, or upload the zip on Claude.ai.

Type the skill name, or just say what you need. The guide skill points you to the right one.

It asks a few questions, shows a plan, and does the work with you. You approve every step that sends or writes.

Questions

What is a skill?

A folder of instructions an AI agent loads when the job calls for it. It turns a general assistant into one that runs a specific process the way a practitioner would.

Which tools does it work with?

Claude Code, Claude.ai, Claude Desktop, and any agent that reads SKILL.md files. Individual skills work with tools like HubSpot, Attio, Pipedrive, Email Bison, HeyReach, Instantly and n8n.

Do I need GitHub?

Not for the free skills. For paid packs in Claude Code you need a free GitHub account, because updates come from a private repo. On Claude.ai you can use the zip instead.

How do updates work?

Run claude plugin update, or turn on auto-update under /plugin, Marketplaces. It is off by default for marketplaces like this one.
