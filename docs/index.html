Questions

What is a skill?
A folder of plain text instructions. Your agent loads it when a matching job comes up and follows the steps we use with clients.
Where does it work?
Claude Code, Claude.ai, Claude Desktop, Cursor, Codex and any agent that reads SKILL.md.
Do I need GitHub?
No. On Claude.ai you upload one file. In Claude Code and other agents the free skills install with one command.
Which Claude plans work?
Uploading one file for a whole pack needs a paid Claude plan (Pro, Max, Team or Enterprise). On the free plan, upload the skills one at a time under Customize, Skills: every download includes a one-by-one version.
How do updates work?
Run the same install command again, or download the new file.
Where should I get the skills?
Only from this page or the GitHub repo linked here. Copies anywhere else are not ours and may have been changed.
