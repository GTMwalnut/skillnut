# Module 6 - Run and report

Load this for Module 6. Two outputs: the 90-day rollout plan, and the monthly partner and creator report.

## The 90-day shape

Partners are core (revenue now); creators and publications are foundation (they compound). Keep the shape; fill it with the programs the user chose.

| Month | Partners | Creators | Publications |
|---|---|---|---|
| 1 Foundation | Program and revenue share finalised and signed off; directory and application live; first handpicked champions approached | Sourcing criteria set and a shortlist vetted; onboarding flow and first brief drafted | Publication list and target-title map |
| 2 Activate | Partner outbound at scale after a small first wave; first partners activated | First small cohort onboarded and posting | Separate campaign, first wave |
| 3 Compound | Active partners referring; second wave | The full first cohort live; first roadmap session | Follow-ups, first conversations |
| End of 90 days | Review: keep, coach or retire each partner and creator; decide what to scale | | |

Write the owner's weekly tasks under each month, and the company's supply list (product access or credits, brand assets, one point of contact, revenue-share sign-off) with dates.

## Monthly report

One report, two parts. Every count reconciles; print each sum.

### Partners

| Measure | Count |
|---|---|
| Applied this month | |
| Approved / declined / pending | (approved + declined + pending = applied) |
| Active partners (at least one referral or deal touch this month) | |
| Referrals received, by rung (refer / influence / self-close) | (sum = referrals) |
| Deals opened, won, lost from partner referrals | |
| Commission due (calculated, not paid) | |

Partner-sourced pipeline and revenue come from the CRM; use the **Lead Attribution Analysis** skill to check the source field is filled and consistent. Commission due goes to the monthly cycle in the Agency Back Office skill, Module 5; paying needs its own go.

### Creators

| Measure | Count |
|---|---|
| Creators active / on break / removed | (sum = creators in program) |
| Posts due this period / drafts received / reviewed / posted | |
| Posts that broke a guideline, and which | |
| Clicks and signups from creator links, if tracked | |

### Narrative

Three short lines: what worked, what didn't, what changes next month (brief theme, partners to coach, creators to nudge). Results in words or the user's real counts; never invented figures.

## Output

`Run and report/`: the 90-day plan, the report template, and each month's filled report as a new dated file.
